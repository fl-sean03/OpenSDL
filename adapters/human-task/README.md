# Human task adapter

Provides structured capabilities for work performed by a person. The reference
adapter records a signed-in operator's attestation and evidence as workflow
output; production deployments can replace it with a queue, dashboard, mobile
form, electronic-signature system, or existing ELN/LIMS task interface.

The adapter does not claim that a submitted attestation independently verifies
physical reality. Deployments decide what identity, witness, evidence, and
approval controls are required.
