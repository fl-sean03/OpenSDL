# opensdl-adapter-cell-surrogate

Example-local, deterministic state-machine adapter for the digital-twin surrogate showcase.

The plugin is installed on demand with:

```bash
uv run --locked --with-editable ./examples/digital-twin-surrogate/adapter ...
```

It is intentionally not an OpenSDL root workspace member. Its behavior is a semantic workflow
surrogate, not equipment, safety, accuracy, or physics validation.
